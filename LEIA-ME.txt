MEU CONFINAMENTO — VERSÃO 2

Esta versão acrescenta o painel de lucro/prejuízo por animal e por lote, mantendo os dados salvos localmente e o funcionamento essencial offline.

COMO PUBLICAR ATUALIZAÇÃO
1. Antes de tudo, abra o app instalado e entre em Backup e dados. Toque em “Baixar backup completo (JSON)” e guarde o arquivo. Como você ainda não cadastrou animais reais, provavelmente não há dados importantes, mas faça o backup por segurança.
2. Extraia este ZIP. Ele contém a pasta meu_confinamento_pwa com os arquivos do site.
3. No mesmo repositório GitHub Pages onde publicou a primeira versão, substitua os arquivos antigos pelos arquivos desta pasta. Não crie um endereço/site novo: mantenha o mesmo endereço publicado.
4. Faça commit/publish no GitHub. Aguarde a publicação terminar.
5. No iPhone, abra o endereço do site no Safari com internet, recarregue a página e aguarde alguns segundos para a atualização offline ser armazenada. Depois abra pelo ícone da tela inicial. Se ainda aparecer a versão antiga, feche o app e abra novamente; pode ser necessário recarregar o site no Safari mais uma vez.

CÁLCULO DO RESULTADO
• Resultado geral = receitas de vendas − compras dos animais − alimentação − custos lançados − sanidade.
• Resultado por lote soma os animais cadastrados naquele lote e os lançamentos vinculados ao lote.
• Resultado individual inclui o valor de compra do animal, despesas ligadas diretamente a ele e rateio por cabeça dos custos e vendas coletivos lançados para seu lote. O rateio considera os animais atualmente cadastrados nesse lote.
• Para atribuir receitas/despesas a um animal, selecione o animal. Para distribuir pelo lote, deixe animal sem seleção e informe o lote. Lançamentos sem animal e sem lote entram no resultado geral, mas não podem ser atribuídos a um lote/animal.
• Não lance a mesma compra duas vezes: use o campo “Valor compra” do cadastro do animal OU um custo de compra vinculado ao animal.
• Para resultados mais precisos, mantenha os lotes atualizados e lance todas as compras, rações, despesas, tratamentos e vendas. O sistema não sincroniza entre aparelhos.

OFFLINE E BACKUP
O aplicativo continua sendo uma PWA e guarda os dados neste navegador/aparelho. O app shell fica disponível offline após abrir o site publicado com internet pelo menos uma vez. Os dados não são enviados para servidor nem sincronizados. Faça backups JSON regulares e guarde-os fora do aparelho.
